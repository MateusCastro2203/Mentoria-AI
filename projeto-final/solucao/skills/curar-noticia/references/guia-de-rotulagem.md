# Guia de rotulagem: categorias

Escolha a categoria pelo que o dev **leva** da notícia.

| Categoria | Quando usar |
|---|---|
| modelos | lançamento ou nova capacidade de um modelo |
| ferramentas | biblioteca, framework, prática de engenharia, tutorial, ou relato de empresa cujo foco é como fizeram |
| pesquisa | estudo, artigo científico, benchmark |
| regulacao | lei, regra, decisão judicial, orientação de órgão público |
| mercado | preço, plano, disponibilidade, licença, dados de adoção, aquisição com efeito prático para devs |

Casos de fronteira:

- Relato de empresa: **ferramentas** se ensina uma técnica; **mercado** se o foco é resultado de negócio ou adoção.
- Anúncio de produto sem detalhes técnicos verificáveis: **não relevante**.
- Aporte ou aquisição: **mercado** só se muda algo para quem desenvolve (preço, plano gratuito, licença); senão, não relevante.
